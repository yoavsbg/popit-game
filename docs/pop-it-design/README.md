# Pop It design reference

Source files of the 6 mock screens (390x844, portrait). They are HTML/CSS and are for READING values only (sizes, colors, spacing, copy, which bubbles are ringed or popped). Do not port the HTML. Rebuild each screen as a Godot scene.

- screens/Main.dc.html       Home
- screens/Levels.dc.html     Level select
- screens/Level1.dc.html     Level 1 (playing)
- screens/Level2.dc.html     Level 2 (two boards, with a wrong-tap penalty shown)
- screens/Result.dc.html     Level clear
- screens/FreePop.dc.html    Free pop
- canvas-layout.json         Canvas layout and notes

Tip: if PNG screenshots of the screens are added to a `screenshots/` folder here, look at those first.
